# student-performance-classification
Classification models (Logistic Regression, Random Forest, CatBoost) predicting course pass/fail on 50K students, with feature importance and diagnostic analysis of model performance ceiling
# Student Performance Classification

Сравнение трёх моделей классификации для предсказания, сдаст ли студент курс, на датасете 50 тыс. студентов, с диагностикой того, что реально ограничивает качество моделей.

## Задача

Предсказать `passed` (сдал/не сдал курс) на основе GPA, риска по GPA, сложности курса, специальности, элективного кода и областей интересов студента.

## Данные

`sdu_course_data.csv` — **синтетический датасет**, сгенерированный для учебных целей (50 000 строк, 14 признаков). Не содержит реальных данных студентов или университета.

## Обработка признаков

- `course_difficulty`, `gpa_risk` — ordinal-кодирование (Easy/Medium/Hard → 0/1/2)
- `major`, `elective_code` — one-hot encoding
- `interest_area` (несколько интересов на студента) — `MultiLabelBinarizer`

## Модели и результаты

| Модель | Accuracy | F1 | ROC-AUC |
|---|---|---|---|
| Logistic Regression | 0.590 | 0.593 | 0.626 |
| Random Forest | 0.556 | 0.577 | 0.578 |
| **CatBoost** | **0.587** | **0.605** | **0.625** |

## Диагностика: почему метрики невысокие

Разница между моделями статистически незначима, поэтому дальше разбиралась не "какая модель лучше", а что вообще ограничивает качество:

- **Баланс классов** — 51.5% / 48.5%, почти идеальный, дисбаланс не влияет на метрики
- **Важность признаков** (CatBoost) — топ-признаки `success_probability` и `gpa`, но даже они слабо коррелируют с исходом (r ≈ 0.23 и 0.17 соответственно)
- **Train vs Test accuracy** — 0.62 vs 0.59, разрыв небольшой, модель не переобучена
- **Подбор гиперпараметров** — практически не меняет метрики (0.587 → 0.587)

**Вывод:** потолок метрик определяется слабой предсказательной силой имеющихся признаков относительно целевой переменной, а не ограничениями модели или неудачным подбором гиперпараметров.
